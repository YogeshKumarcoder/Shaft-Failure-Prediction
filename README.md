# Shaft Failure Prediction (Random Forest surrogate)

Predicts the factor of safety (FoS) of a solid circular shaft under combined bending and torsion, using the distortion-energy (von Mises) criterion, and flags designs that are likely to fail.

## Problem

Inputs: shaft diameter `d`, bending moment `M`, torque `T`, yield strength `Syt`.

Target: `n_MDET = Syt / sqrt(sigma^2 + 3 tau^2)`, with `sigma = 32M / (pi d^3)` and `tau = 16T / (pi d^3)`. A design is labelled as failing when `n_MDET < 1`.

## Data

Synthetic, 50,000 rows, seed 42 (`data_generation.py`).

- Ranges: `d` 20-150 mm, `Syt` 250-1250 MPa (typical shaft steels, from Bhandari's Design Data Book).
- Sampling: instead of drawing `M` and `T` directly, the target FoS is drawn first (log-normal, median 1, clipped to 0.2-5) together with a bending/torsion mix angle (0-90 degrees). `sigma` and `tau` are then solved so the von Mises FoS equals the target, and `M` and `T` are back-calculated. This keeps control over the label distribution and covers pure bending, pure torsion and everything in between.
- All five classical failure theories (max shear, distortion energy, max principal stress, max principal strain, total strain energy; Poisson's ratio 0.3) are computed as columns. Only the distortion-energy target is modelled here.
- Checks: recomputing the von Mises FoS from the sampled `d, M, T, Syt` reproduces the sampled target, and `n_MDET >= n_MSST` holds on every row (distortion energy is less conservative than max shear).

## Models

Test R^2 on a random 80/20 split:

| Model | Features | R^2 |
|---|---|---|
| Linear regression | d, M, T, Syt | 0.19 |
| Linear regression | sigma, tau, Syt | 0.61 |
| Random forest (100 trees) | d, M, T, Syt | 0.96 |
![feature_importance.png](plots/file.png)

Linear regression on raw inputs cannot represent the cubic dependence on `d`. Giving it `sigma` and `tau` helps, and the random forest learns the non-linearity from the raw inputs.

## Fail / safe decision

The regression output is turned into a decision with `predicted n_MDET < t`. Missing a failing shaft is worse than a false alarm, so `t` is set above 1.
![actual_vs_predicted.png](plots/file.png)

The threshold was chosen on out-of-fold predictions from the training split only (5-fold, about 40,000 predictions), and the test split was evaluated once.
![threshold_curve.png](plots/file.png)

Out-of-fold results:

| t | FNR (missed failures) | FPR (false alarms) |
|---|---|---|
| 1.05 | 0.94% | 9.25% |
| 1.08 | 0.37% | 14.35% |
| **1.10** | **0.20%** | **18.08%** |
| 1.12 | 0.11% | 21.49% |
| 1.15 | 0.03% | 26.65% |

Test set (10,000 rows):

| t | FN | FP | Fail recall | FPR | Accuracy |
|---|---|---|---|---|---|
| 1.00 | 215 | 130 | 95.63% | 2.56% | 96.55% |
| **1.10** | 12 | 930 | 99.76% | 18.30% | 90.58% |

Moving `t` from 1.0 to 1.10 removes most missed failures at the cost of flagging more safe shafts, so plain accuracy goes down while the metric that matters for safety goes up.

Plots are in `plots/`: actual vs predicted, the threshold curve, and feature importance.

## Limitations

- Labels come from a closed-form formula, so the model is a surrogate for it. It is useful as a pipeline when the ground truth is expensive to compute (FEA, experiments), not as a replacement for this formula.
- `n_target` is centred on 1, so the test set is dense near the failure boundary on purpose. Error rates here are harder than for typical designs, which use FoS of 1.5 or more.
- The 99.8% fail recall is an average over the sampled design space. On out-of-fold residuals near the boundary, the error is about 1.6-1.8x higher for small diameters, low yield strength and bending-leaning mixed loading.
- The model is slightly biased upward near the boundary (about +0.012 FoS), which is why a threshold above 1 is needed.
- Misses do not drop to zero in the range tried: 6 of about 20,000 failing designs are still missed at t = 1.15 (out-of-fold).
- Single material family (ductile steel, one yield strength per shaft), static loading only, Poisson's ratio fixed at 0.3.
- Behaviour outside the sampled ranges (extrapolation) has not been evaluated.
- Predictions saturate above FoS ≈ 2.5, so the regression output is not reliable in the high-FoS tail; this does not affect the fail/safe decision.
## Reproduce

```
pip install -r requirements.txt
Run data_generation.ipynb from top to bottom.     
# writes data/shaft_failure.csv
```

Then run the notebook from top to bottom. The trained model (`models/rf_mdet.joblib`, about 100 MB) is not committed and is regenerated by the notebook. The threshold and seed are stored in `models/config.json`.
